## What I work on

- **Laravel & Livewire products**: billing flows, admin panels, queues and integrations, built to be read and changed by the next developer.
- **Open-source PHP packages**: a framework-agnostic core with thin framework adapters, small public APIs, and Blade views you can override one file at a time.
- **Email infrastructure**: inbound webhooks, conversation threading, reply headers, auto-reply detection, and delivery tracking.
- **Supply-chain security**: Go CLIs that catch dependency confusion, typosquatting and known-malicious packages before they ship.
- **Developer experience**: Dockerized local environments, CI that fails for the right reasons, and tests that document behavior.
